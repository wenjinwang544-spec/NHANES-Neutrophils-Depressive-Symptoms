# Data sources and rights review

Checked 27 October 2026. This is a provenance and distribution review, not legal advice or a new data license.

NHANES: CDC provides public-use data and documentation for download and analysis; restricted data are a distinct product. The pipeline uses public-use modules. Download from the original source, retain cycle/module citations and follow CDC confidentiality conditions. This candidate does not redistribute participant-level records. Sources: https://www.cdc.gov/nchs/nhanes/about/ and https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/ .

PGC MDD2025: the official PGC download list points to DOI 10.6084/m9.figshare.27061255. The required file is `pgc-mdd2025_no23andMe-noUKBB_eur_v3-49-24-11_formatted.tsv.gz`. The Figshare API metadata labels the record CC BY 4.0; the distributed README additionally states that commercial or for-profit use requires prior permission from the PGC Data Access Committee, prohibits identification and requires appropriate citation. These two layers must both be recorded; this review does not resolve their legal interaction. No full PGC file or harmonized variant-level derivative is bundled. Sources: https://pgc.unc.edu/for-researchers/download-results/ , https://figshare.com/articles/dataset/GWAS_summary_statistics_for_major_depression_PGC_MDD2025_/27061255 , https://api.figshare.com/v2/articles/27061255 . The dated metadata and README are retained in the private audit evidence.

OpenGWAS: IDs ieu-b-34 and ieu-b-32 identify the blood-cell exposures; ukb-d-30080_irnt identifies the platelet phenotype. OpenGWAS access terms do not themselves grant dataset rights; dataset-specific owner permissions must be checked. Authentication, allowance limits and LD/clumping reference versions can prevent offline upstream reconstruction. Tokens must come from environment variables and must never be stored in code. Source: https://opengwas.io/policies/eula (especially dataset-rights clauses 2.3–2.5). No blanket redistribution permission is inferred for the two Vuckovic exposure datasets; original dataset license metadata still needs to be documented.

Neale Lab: its UK Biobank GWAS FAQ permits unrestricted download and use of summary results and requests citation of the release page. This does not make UK Biobank individual-level genotypes public. Source: https://www.nealelab.is/uk-biobank/faq . No individual-level UK Biobank data are used or bundled.
